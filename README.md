# DSA Practice — Java Exercises Repository

Professional collection of Java practice exercises designed for hands-on learning and skill refinement. This repository contains multiple focused examples organized into folders; each folder contains self-contained Java programs and supporting files.


Getting started
- Prerequisites: Install a JDK (version 8 or later recommended) and an IDE or a terminal with `javac`/`java` available.
- Compile a single file from the repository root or inside a folder:

```bash
javac path/to/Example.java
java path.to.Example
```

- Alternatively, open the repository in your favorite Java IDE (IntelliJ IDEA, Eclipse, VS Code with Java extensions) and run programs directly from the editor.

Development guidelines
- Keep changes focused and minimal — one logical change per commit.
- Follow standard Java naming and formatting conventions.
- Add a short comment at the top of new files describing the purpose and how to run them.

Contributing
- Fork the repository, create a branch for your changes, and open a pull request.
- Include a brief description of what you changed and why.
- Ensure new code compiles and includes brief usage notes.

Contact
- For questions or suggestions, open an issue or submit a pull request.
